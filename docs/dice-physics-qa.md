# 骰子物理投掷验收（2026-10-25）

原问题：欧拉角动画直接依赖最终骰面，起滚会跳姿态；旋转、弹跳和落地互相独立，缺少碰撞响应。

本次改为 Rapier 0.12.0 刚体模拟：固定 120 Hz 步长，简化凸体碰撞模型，重力、摩擦、恢复系数、角阻尼、桌面及骰子之间的碰撞。桌面书本另有静态碰撞体。骰子从当前显示姿态起滚，模拟休眠后结束；不施加结果修正扭矩、不在末帧强制改朝向。镜头在投掷时保持稳定，屏幕范围过滤避免接受飞出视野的轨迹。

为保持原先无偏 D100 规则，先保留 crypto 随机结果，再搜索实际落在对应两张骰面的物理轨迹，按固定步长记录并插值回放。搜索时保留已经满足第一颗骰子结果的投掷参数，继续完整模拟两颗骰子，避免等待大量无效组合。准备失败时保留原随机结果供重试。物理模块单独分包，在场景加载后后台预热。

验证：
- 本地完整工作区构建通过，13 项测试通过。
- 当前骰子、待接入的古铜骰子各按桌面/手机尺寸验证，共 48 次指定结果的物理轨迹，覆盖十张骰面及 00、99。起点连续，最终真实骰面与结果一致，结束前刚体已休眠。
- 检查实际模型顶点保持在可见桌面之上，检验固定步长回放的位置；没有依赖动画末帧改写结果。
- 独立发布版本仅包含现有线上骰子，构建通过，10 项测试通过（24 条物理轨迹）。未发布尚缺第二套模型的外观选择界面。

限制：碰撞体是保留外形的简化凸体，不逐个模拟雕花凹槽；轨迹是预计算的物理回放，不接受飞行中再次拖拽。自动化准备耗时不是手机实机性能结论。
