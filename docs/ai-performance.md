# 生成速度与模型分工

2026-10-24：批量评估、短手记、前后端流式正文和终局长传记已落实。

| 场景 | 调用策略 |
|---|---|
| 难度、全部可选卡匹配、奖励风险事前锁定 | 一次结构化评估；M3关闭思考 |
| 换卡 | 本地即时重算；零模型请求 |
| 每回合 | 先保存程序事实；AI短手记可选，中文目标40–80字 |
| 短手记 | M3关闭思考；正文流式呈现 |
| 终局七章传记 | M3.1-Flash，medium；各章流式生成并单独保存 |
| 一次评估格式修复 | M3.1-Flash，medium；不因换卡触发 |

M3.1-Flash必须思考，官方默认档位为max，因此代码明确传medium；服务端仅允许low/medium/high，不把未识别配置或max静默传给模型。推理内容和事前隐含奖励/风险不进入前端正文流。

生成中的文字为草稿；完整输出通过来源与结构化状态核验后才保存。不合格时清空草稿、最多重试一次；失败不会重新投骰、重复发牌或改写结算。网络中断可用同一requestId读取已完成回执。

64项自动检查通过。真实供应商检查中，中英文各九回合与七章传记通过来源核验、模型档位及刷新续读检查。中文短手记65字，本次约1.5秒开始出字、2.2秒完成；英文约2.8秒开始出字、3.9秒完成。传记首段等待因章节、排队、思考和重试不同而变化；这些是单次样本，不代表固定延迟，也不是相对旧版的受控速度对照。逐章数据见[机器可读验证](ai-performance.json)。

此外修正了无必要重试：非末回合不再强制AI生成尚未使用的终局成就；最后回合仍要求与实际行动有关的称号。
