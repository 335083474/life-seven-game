# 逆转人生 · 命运档案馆

从七岁开始，经历七个人生阶段的网页视觉交互原型。

## 运行

使用静态 HTTP 服务打开 `index.html`，无需安装依赖或配置密钥。

```sh
python -m http.server 8767
```

## 当前能力

- 初始卡牌、固定事件、自由事件与 D100 演示
- 黑天鹅、卡牌成长、人生手记、传记文字下载
- 桌面和手机布局

这是前端视觉原型。AI 主持、真实多人房间、完整规则引擎、支付和广告均未接入。数据仅保存在当前页面内存中，刷新后重置。

原始文件来自 ChatGPT 对话“制作电子版游戏”中用户确认的网页视觉原型；发布时不改变设计和规则。
