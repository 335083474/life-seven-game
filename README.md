# 逆转人生 · 命运档案馆

从七岁开始，经历七个人生阶段的单人人生游戏。当前为 `solo-1.1-preview` 单人技术预览，平衡数值仍是测试参数。

已按新版 `LIFE-GDD-PRD-001 V1.0` 的70条验收和26项未决逐项核对：[开发对照与补漏记录](docs/development-audit.md) / [机器可读映射](docs/development-audit.json)。没有把NPC测试当作真实联机验收，也没有把未决规则自动升级为正式规则。

独立的 [Three.js 命运之书交互样章](https://335083474.github.io/life-seven-game/book/) 已提供开书、弯曲翻页、选卡及两枚十面骰组成 D100 的试玩；[源码与运行说明](prototype/README.md)。样章使用预设演示内容，与正式存档分开。

## 运行

试玩：https://335083474.github.io/life-seven-game/

使用静态 HTTP 服务打开 `index.html`。网页连接独立的 Cloudflare Worker；MiniMax 密钥仅保存在服务端 Secret 中。

右上角「语言」可切换简体中文 / English，默认简体中文，浏览器会记住选择。界面、卡牌、插画文字、规则、提示、手记、传记与摘要跟随语言；玩家自行输入的姓名和编辑框原文保留。MiniMax 新文案按所选语言生成，已有 AI 文案按需翻译并随存档缓存，首次切换可能需要等待。翻译沿用原有服务限额；失败可重新选择语言重试，不会重掷骰子或重做结算。内部卡名与规则枚举保持稳定，翻译只用于显示。

```sh
python -m http.server 8767
```

## 单人规则

- 七岁固定父母＋三种随机天赋；随后九个常规回合，按固定事件→自由事件→黑天鹅推进，不能跳章重复领奖。
- 升学与辍学分支、职业、婚恋、生育、事业危机、父母离世、孩子独立、余生；提前结婚与已有孩子不会被后续固定事件重置。
- 最多七种元素，普通重复元素升级Ⅰ→Ⅱ→Ⅲ；Ⅱ贡献翻倍，Ⅲ保持Ⅱ能力并记录典藏，失牌整张失去。父母、家庭、孩子采用独立关系规则。
- MiniMax 在掷骰前锁定角色奖励、因果失牌候选、父母代偿与旧机遇资格。事前只展示风险类型，事后可查候选。普通失败不失牌，大失败真实扣牌，合作全事件仅一张直接损失。
- 单人可邀请最多两名系统人物合作，消耗各自本回合行动；同名贡献递减，资源不重复计算。系统人物保有自己的资源、成长、行动与命运。
- 健康保护次数、父母自愿代偿、婚姻、离婚、复婚、夫妻借卡、赠送交换、抚养权、孩子与快乐独立变化均实际结算。
- 大成功留下可用于后续相关失败的一次机遇重掷，保留较好结果；末回合大成功转为特殊成就，不改变生存判定。最终黑天鹅与所有取舍完成后，七种元素存活，不足则死亡。
- 服务端保存整局状态与事件账本；刷新可续玩，并发与重复请求不会重复领奖或换骰。卡满与保护选择必须先完成。
- 免费完整事实手记、七章 AI 传记与结局摘要下载；手机、桌面布局和键盘对话框。

黑天鹅使用服务端D100：01—65无事，66—100厄运，不会发正向奖励。夫妻同回合黑天鹅先收集再统一结算健康保护。未确认白名单的重大亲子连锁默认关闭。35%属于当前测试参数，不宣称是原版已定概率。完整来源、用户选择的测试方向及未最终冻结的实现参数见 [rules-contract.json](rules-contract.json)。

参数集中于 `backend/settings.mjs`，新局及行动保留规则快照；按真实出生年龄决定孩子独立。正文可打开「查看故事依据」，事实手记可搜索和按章筛选。来源ID、状态检查和哈希不能证明全部文学语义无误，仍需质量抽检。没有来源元数据的旧文案不会被伪造为新版已验收文案。

## MiniMax 命运司书

- 自由事件：输入行动、选择最多两张元素、邀请系统人物，点击“请司书评估”，阅读难度、卡牌匹配及成功率，再确认掷骰。换卡只重算贡献，同一目标在本回合沿用基础难度。可以主动放弃尚未使用的自由行动机会，不制造虚假的骰子或奖励。
- 服务端依照原型的固定公式计算成功率，以加密随机数生成 D100；MiniMax-M3 只评价语义与撰写叙事，不能指定概率或骰点。
- 同一评估的骰点持久保存，网络错误后重试不会重新掷骰。失败不会伪装成本地 AI 回应。
- 规则结算先保存，事件叙事独立重试；AI不可用也不改变已结算的卡牌与骰点。事实手记始终可读，不伪装成本地 AI 回应。
- 终局按七章逐章撰写传记，可中断并继续；完整回顾免费阅读，摘要可免费下载。完整故事文字版的广告解锁、付费精装PDF尚未开放。
- 当前公开试玩每天最多200次模型调用，每个会话每天80次、每个IP每分钟12次；一次事件评估、一次叙事、每章传记各占一次。额度耗尽会明确提示，保留已完成的进度。
- 进行中整局存档最长30天。终局完整记录48小时到期后不可访问，每15分钟定时清理数据库状态及所有含故事的重试回执；不承诺永久云端保存。旧接口的独立AI操作记录仍为24小时，不保存原始IP，密钥与完整模型原始响应不写入日志。

真实多人、广告、支付和精装PDF不在本次单人实现范围。旧视觉原型只有内存状态，不能可靠迁入新的服务端存档；新版请刷新后新开一局。规则表仍含明确标注的平衡测试参数，不能称为官方完整复刻。

## 服务端维护

需要 Node 22+、Cloudflare 的 Workers/D1 权限及自己的 MiniMax 密钥：

```sh
npm ci
npm test
npm run migrate:remote
node scripts/configure-secrets.mjs
npm run deploy:api
```

本地确定性全流程验收（不会调用付费模型）：

```sh
node scripts/dev-solo.mjs
```

该脚本仅在本地将前端API地址改写为本地验收服务，没有生产强制骰点接口。`node scripts/verify-minimax-solo.mjs` 使用本机既有密钥实测新的多人语义评估、叙事、单章传记，报告写入被Git忽略的 `artifacts/solo-release/`。

配置位于 `backend/wrangler.jsonc`，复用时须更换 Cloudflare 账户和 D1 ID；前端接口地址位于 `ai-client.js`。配置密钥的脚本读取本机 mmx 已有配置，或 `AI_LIVE_MINIMAX_API_KEY` / `MINIMAX_API_KEY` 环境变量，通过标准输入传递，不写进文件或命令参数。不要将 `.dev.vars`、环境文件或 Wrangler 缓存提交到仓库。

单人接口：`POST /api/life/new`、`load`、`assess`、`action`、`narrate`、`memoir`、`localize`。浏览器随机Bearer标识持久保存在本机；只有该标识可读取自己的存档。写入使用版本比较和原子事务，`requestId`保存幂等回执。每次动作的卡牌、关系、骰点均从D1状态派生，不接受浏览器提交的任意手牌或经历。`GET /health`仅公开配置状态。旧独立AI接口保留兼容旧原型，但不能修改新单人存档。

参考：[MiniMax 官方接口](https://platform.minimax.io/docs/api-reference/text-openai-api)、[Cloudflare Secret 配置](https://developers.cloudflare.com/workers/configuration/secrets/)。

原始视觉来自 ChatGPT 对话“制作电子版游戏”中用户确认的宿命文学版画方案，保留深墨绿、旧纸色、暗金线刻和原始SVG图形。规则按原讨论的确认与测试方向补齐，后续以版本化规则合同继续平衡。


### 等待时间与模型分工（2026-10-24）

- 一次结构化评估覆盖玩家和参与系统人物的全部可选元素；换卡只在浏览器用同一份评估重算概率，不调用模型。目标、参与者或关系对象变化才重新评估。评估不生成剧情。
- 平时先保存程序裁决与简短事实手记；AI短手记按需生成，中文目标40–80字。完整七章传记只在终局按需生成。
- `Accept: application/x-ndjson` 可用于 `life/narrate` / `life/memoir`。事件为 start、reset、draft（完整当前草稿文字）、result（已验证并保存的状态）或 error。未通过来源校验的草稿不写入存档；重试先清空草稿。普通JSON调用继续兼容。
- M3：日常评估、翻译、短手记，`thinking.type=disabled`。M3.1-Flash：终局传记与一次评估格式修复，`thinking.type=adaptive`、明确 `reasoning_effort=medium`，不沿用供应商默认max；可在服务端改为high。推理内容不发给浏览器。
- 新模型的思考计入输出预算，因此复杂调用单独预留预算；每局元数据保留模型、思考档位、首段文字与完成耗时。首字延迟不是零，供应商排队/思考仍会影响等待。

参数依据：[MiniMax官方模型调用](https://platform.minimax.cn/docs/guides/text-generation)、[兼容接口字段](https://platform.minimax.io/docs/api-reference/text-openai-api)。M3.1-Flash不支持关闭思考，省略effort默认max。
